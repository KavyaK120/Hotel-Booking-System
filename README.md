# Hotel Booking System

## Overview

The Hotel Booking System is a web-based application designed to simplify hotel reservation processes for customers and hotel management.

## Features

- User Registration
- User Login
- Hotel Listing
- Hotel Booking
- My Bookings
- Cancel Booking

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database

- MySQL
